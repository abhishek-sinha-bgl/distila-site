Evidence-decision engine · Published architectural thesis

Frontier intelligence can propose.
Evidence still has to earn authority.

Epistamate is built around a separation that becomes more important as models improve: reasoning capability, evidentiary authority and professional judgement are not the same thing.

Use the strongest available intelligence for cognition. Preserve a separate, inspectable path for what the evidence warrants and what a human authorised.

request → bounded plan → optional model advice → explicit execution → acquired source → exact support → evidence posture → human review → output → reassessment
Six engine properties ↓Authority model ↓Published architecture
Six co-present properties

The contribution is not one technique.
It is the architecture around them.

01 · ADDRESSABLE CLAIMS

Control below the report level.

Consequential propositions remain durable objects that can be supported, qualified, contradicted, reviewed and reused independently of the prose around them.

02 · EVIDENCE POSTURE

No magic confidence number.

Directness, source role, exact support, independence, applicability, contradiction, recency and sufficiency remain inspectable dimensions.

03 · ADVERSARIAL CHALLENGE

Try to break the conclusion.

Models can surface counterevidence and alternative explanations, but challenge changes canonical posture only when the evidence justifies it.

04 · PERSISTENT GAPS

Unknowns survive synthesis.

Missing evidence is a durable research object and possible Research Further target, not a disclaimer that disappears after drafting.

05 · CUMULATIVE STATE

Reuse without laundering old answers.

Inherited evidence can be reconsidered for freshness, applicability and contradiction. Inherited answer authority is not automatically reusable.

06 · BIDIRECTIONAL OPERATION

Question-led and source-led work share standards.

A research question can drive acquisition; a supplied report can drive verification. Both enter the same evidence and review spine.

Authority model

Three kinds of authority.
Never silently collapsed.

MODEL / REASONING

Can propose.

Search lanes, interpretations, triage, challenge and drafts. Model agreement can improve process robustness; it is not independent evidence.

EVIDENCE

Must be earned.

Acquired source identity, exact support, evidence function, work/family lineage, independence, scope and other domain gates determine what a proposition can claim.

RESEARCHER

Can judge and authorise.

Human review is essential governance. It records acceptance, rejection, deferral and continuation authority without pretending that approval strengthened the source evidence.
