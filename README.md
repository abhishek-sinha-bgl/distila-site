## Retired desktop preview

This repository formerly distributed **Distilapp Preview 3 (v0.11.1-1)** installers. These obsolete desktop preview binaries were removed from the website branch on **24 October 2026**. They are not releases of the current Research Workspace, and should not be offered as current downloads.

Older preview notes remain available in Git history. Current application development takes place outside this public website repository.

## Deployment hygiene

- Batch related editorial changes into one reviewed commit to minimise Vercel deployments.
- Do not commit installers, archives or temporary binaries to the website deployment.
- Preserve live pages, screenshots, published research and search metadata unless their usage has been verified.
- Git history and Vercel deployment history are different; removing old assets from the current branch reduces **future** deployment output but does not delete older Vercel deployments.

The public website should describe evolving product capabilities accurately and distinguish demonstrated features from planned work.
