## What's New

### Preview 3 (v0.11.1-1)
- Improved research quality and dedup behavior in iterative runs.
- Added cross-topic grounding for better continuity across related topics.
- Stabilized token accounting and topic/session token visibility.
- Tightened citation filtering to reduce placeholder/noisy references.
- Improved URL summarization path and fallback extraction quality.
- Better provider fallback behavior under rate limits and transient failures.

### Preview 2
- Added first-run sample topic walkthrough.
- Added thesis/scope-driven topic intent controls.
- Improved right pane layout, activity visibility, and quality metrics.
- Added detailed brief mode and stronger pipeline UX guidance.
